# 👟 Walkin - Sneaker E-Commerce Website

Walkin is a modern and responsive sneaker e-commerce website designed to provide a seamless online shopping experience. It features a clean user interface, secure authentication, product browsing, shopping cart, wishlist, and checkout functionality.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* User authentication (Login & Signup)
* Browse sneakers by category
* Product search and filters
* Product details with images, sizes, colors, ratings, and reviews
* Shopping cart and wishlist
* Secure checkout
* Prices displayed in Indian Rupees (₹)
* Order summary and confirmation
* Simple admin panel for product management

## 🛠️ Tech Stack

* React.js
* Tailwind CSS
* JavaScript
* HTML5
* CSS3

## 📂 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/walkin.git
```

2. Navigate to the project:

```bash
cd walkin
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
